# 05. 探索UI

1つのグラフを3つのビューで見せ、選択・絞り込み・現在地を共有します。
画面の構成要素は現行の銀河UI（`index.html`）と年表（`evolution.html`）の部品を引き継ぎます。

## 1. 画面の骨格

```
┌──────────────────────────────────────────────────────────────┐
│ Manabi Map   [ 銀河 | 時の河 | 問いの星座 ]      検索  足あと  │ ← ビュー切替（選択は保持）
├──────────────────────────────────────────────────────────────┤
│ いまの問い：言葉は思考を作るのか、思考が言葉を作るのか。        │ ← 現行の大見出しと同じ位置
│ 14の学びが、この問いの重力に引き寄せられています。              │
│                                                              │
│        ·  ✦ 哲学1      ·                    ┌─────────────┐ │
│    ·        ╲      ✦ 第8部                   │ YOU ARE HERE │ │
│        ✦ 第5部 ─────╱    ·                   │ 第5部        │ │ ← 詳細カード
│   ·        ╲                                 │ 言葉と思考の旅│ │   （現行カードを拡張）
│       ✦ 東洋2   ·     ·                      │ ❝問い❞       │ │
│                                              │ つながり 4   │ │
│                                              │ 開く 読む 聴く│ │
│                                              │ AIと考える → │ │
│                                              └─────────────┘ │
├──────────────────────────────────────────────────────────────┤
│ レンズ: すべて 考える 学ぶ 言葉 道具 価値 …   深さ ━━●━━━━   │ ← 現行のレンズと深さスライダー
│ 来た道: 第3部 › 第8部 › 第5部                     道を共有    │ ← 新規：パンくず
└──────────────────────────────────────────────────────────────┘
```

共通の状態は4つだけです。これをURLに載せます。

| 状態 | 意味 | 例 |
|---|---|---|
| ビュー | どの見え方か | 銀河／時の河／問いの星座 |
| 焦点 | いま選んでいるノード | `work:part5` |
| 絞り込み | レンズ・シリーズ・時間範囲 | 言葉レンズ、哲学＋本編、紀元前500年〜現在 |
| 道 | たどってきたノードの並び | part3 → part8 → part5 |

## 2. ビュー1：銀河（概念の空間）

現行の銀河を、作品が増えても読めるように「深さ」で見える情報を切り替えます。
現行の深さスライダーにある3段階の文言を、そのまま3段階の表示に対応させます。

| 深さ | 現行の文言 | 見えるもの | 操作 |
|---|---|---|---|
| 遠景（0–33） | 全体を眺める | シリーズ＝星団・渦状腕。シリーズ名と作品数。大きな問いが淡く浮かぶ | シリーズを選ぶ、問いを選ぶ |
| 中景（34–69） | 部のあいだを歩く | 作品＝星（題名つき）。選んだ作品の接続線。訪問済みは灯る | 作品を選ぶ、線をたどる |
| 近景（70–100） | 一つの問いへ潜る | 1作品の周りに、話・概念・人物・出来事・メディアが惑星のように並ぶ | 話を開く、概念から隣の作品へ跳ぶ |

設計上の決めごと：

- **配置は固定。** 作品の位置は事前に計算した座標を使い、訪れるたびに同じ場所にあります（毎回動く力学レイアウトは使わない）。「あの星は左下」と覚えられることが、地図としての価値です。
- **近さに意味がある。** 同じシリーズは同じ星団に、概念と問いを多く共有する作品ほど近くに置きます。新しいシリーズは、つながりの深い既存作品の近くに現れます（「AIの源流」は第7部・第8部の近く、など）。
- **雑多でよい。** シリーズの数や分野が揃っていなくても成立するよう、遠景では系統（西洋哲学と東洋哲学など）をゆるく囲んで見せ、どこにも属さない単発の作品も1つの星として置けます。
- **塵は本当の所属で。** 現行は note・Podcast を `番号 % 作品数` で仮に割り当てていますが、実際の `relatedParts` で作品の周りに漂わせます。記事の多い作品ほど明るく見えます。
- **線は必要なときだけ。** 既定で出すのは焦点ノードの接続のみ、同時に最大12本。レンズや問いを選ぶと、該当する作品が現行同様に内側へ集まります。
- **背景の星空（WebGL）は現行のまま**装飾として使います。

## 3. ビュー2：時の河（138億年）

現行の年表の対数軸・ズーム・レンズを使い、**シリーズごとの流れ**を重ねます。

```
        138億年前        46億     700万    1万     紀元前500   1500  1900  現在  未来
宇宙・生命   ●───●──────●───●───●
人類史(本編)                    ━━━━━━第9部 身体という時間━━━━━━━━━━━━━━━
                                         ━━━第4部 文字と知識━━━━━━━━━━━
                                                  ●文字  ●紙   ●印刷  ●検索
哲学                                              ●ソクラテス  ●カント ●フッサール
東洋哲学                                          ●ブッダ ●孔子
数学                                                         ●微積分 ●確率
EDU（教育史）                                                    ●義務教育 ●GIGA
                                         ▲ 選択中：紀元前5世紀（±100年）
```

- **流れ（レーン）**：シリーズごとに1本。作品は時間の**帯**、出来事は**点**、概数は**ぼかした点**。
- **同時代を見る**：縦にカーソルを置くと、その時代に各シリーズで何が起きていたかが揃って光ります（例：紀元前5世紀にブッダ・孔子・ソクラテスが並ぶ＝現行の「枢軸時代」が一目で分かる）。
- **範囲を選ぶ**：時間軸をドラッグして期間を選ぶと、他のビューもその期間で絞り込まれます。
- **重なりの処理**：点が密集する箇所は数字つきのまとまりにし、拡大でほどけます。現行の「中核／すべて」の切替は維持。
- 既存の年表ページの縦スクロールの読み物（時代区分ごとのカード）は**そのまま残します**。時の河は、その上部にある横軸の拡張という位置づけです。

## 4. ビュー3：問いの星座

ManabiMapのコンセプト「知の重力レンズ」を最も直接に表すビューです。

- 中央に**問い**。その周りに、問いに関わる作品・出来事・人物が、関わりの強さに応じた距離で並びます。
- 外周には隣の大きな問い。選ぶと中心が入れ替わり、共通するノードは画面に残ったまま移動します（何が2つの問いをつないでいるかが見える）。
- **並べ替え**：「時代順に並べる」を押すと、同じノードが古い順に円周へ整列します。問いへの答えの変遷が読めます。
- **立場を見る**：`answers` エッジを持つ人物・作品は、短い要約（その問いにどう答えたか）をカードに表示します。
- 既存の「問いに連れていって」ボタンは、ここへの入口として使います（ランダムな問いへ移動）。

## 5. 詳細カード

現行の銀河カード（シリーズ名・部番号・題・問い・「部をひらく／読む／聴く」・AI対話）に、次を足します。

| 追加要素 | 内容 |
|---|---|
| **つながり** | 接続先を種類別に最大5件。各行に理由の一文（`why`）。行を選ぶと、開かずに焦点だけ移動 |
| **同じ問いの別の答え** | 同じ大きな問いを共有する、**別シリーズ**の作品を優先して1〜3件 |
| **同じ頃** | 時間が重なる出来事・作品を1〜3件 |
| **ここから時の河へ／問いの星座へ** | 焦点を保ったままビュー切替 |
| **AIと考える** | 焦点と道から対話文を生成（下記7） |

カードはノードの種類で出し分けます（作品・出来事・概念・問い・人物）。本文は既存ページへのリンクで、カード内に長文は持ちません。

## 6. 操作の一覧

| やりたいこと | マウス・タッチ | キーボード |
|---|---|---|
| 動かす | ドラッグ／1本指 | 矢印キー |
| 深さを変える | ホイール／2本指／スライダー | `+` `-` |
| 選ぶ | クリック／タップ | `Tab` で順に移動、`Enter` |
| 接続先へ移る | 線またはカードの行を選ぶ | カード内を `Tab`、`Enter` |
| 戻る | 「来た道」を選ぶ／ブラウザの戻る | `Backspace` または `Alt+←` |
| ビューを切り替える | 上部のタブ | `1` `2` `3` |
| 探す | 検索欄（題・人物・概念・問い） | `/` |
| 2つをつなぐ | ノードを長押し →「ここへの道を探す」 | カード内のボタン |
| ランダムに跳ぶ | 「問いに連れていって」 | `R` |
| 閉じる | × | `Esc` |

**「2つをつなぐ」**は新しい探索の要です。たとえば「数学2（確率統計）」と「第18部（勘違い）」を選ぶと、
`数学2 —不確実性→ 第6部 統計 —判断の誤り→ 第18部` のように、理由つきの最短の道を表示します。
道が見つからない場合は「まだ道がありません」と表示し、それ自体を編集側の課題リストに記録します。

## 7. AIとの対話

現行の `ai-handoff.js`（対話文をコピーして好みのAIを開く）を使い、渡す材料を増やします。

- 焦点ノードの題・問い・要約
- たどってきた道（最大5ノード）と、各区間の理由
- 選択中のレンズ

例：「私はManabiMapで『蒸気の時代 → つながる世界 → 言葉と思考の旅』とたどってきました。
共通する問いは『道具を使うことと、道具に使われることの境界はどこか』です。まず私の考えを聞いて、
次に別の時代の見方を1つ示してください。」

答えを教えさせるのではなく、問い返してもらう文面にする方針は現行どおりです。

## 8. 既存ページとの行き来

| 場所 | いま | Atlas導入後 |
|---|---|---|
| トップ `index.html` | 21作品の銀河 | 全シリーズの銀河（遠景から始まる） |
| `map.html` | 本編は自動、哲学系は手書きカード | 全シリーズをグラフから自動生成。リスト表示としてAtlasと対になる |
| `evolution.html` | 独立した年表 | 上部が時の河。出来事カードに「この出来事を扱う作品」 |
| 作品ページ | 「学びの地図の現在地」パネル（本編のみ） | 全シリーズ共通のパネル。次の部に加えて「別シリーズへの橋」を理由つきで表示 |
| `questions.html` | 部を選んで対話 | 問いの星座への入口を追加 |

作品ページの本文には触りません。パネルを差し込む場所と方法は [06](06-technical-design.md) を参照。

## 9. アクセシビリティ

現行の銀河はキーボードと読み上げで使えません。Atlasでは最初から要件とします。

- **裏にリストを持つ**：canvas と同じノードを、見出しつきのリスト（`<ul>` とボタン）として常にDOMに持ちます。フォーカス移動・読み上げはリスト側で行い、canvas はその視覚表現です（年表が出来事を `<button>` で生成している方式の一般化）。
- **「リストで見る」切替**：同じ絞り込み・同じ焦点のまま、表形式で読めます。低スペック端末や canvas が使えない環境の代替も兼ねます。
- **読み上げ**：選択時に「第5部 言葉と思考の旅。哲学シリーズ第1部ほか4件とつながっています」と通知。
- **動きを減らす**：OSの設定に従い、移動アニメーションを即時切替にします（現行も一部対応済み）。
- **色に頼らない**：シリーズは色に加えて形・ラベルで区別。文字と背景のコントラスト比は4.5:1以上。
- **タッチ対象**：44px以上。

## 10. スマートフォン

- 縦画面ではカードを下からのシートに。canvas は上半分、シートは引き上げで全画面。
- 時の河は横スクロールを基本にし、レーンは選択中のシリーズ＋1本に絞ります（全シリーズは「重ねる」で追加）。
- シリーズが10を超えたら、PCでも時の河のレーンは「選択中＋関連の強い順に数本」を既定にし、残りは折りたたみます。
- 銀河の背景の星は現行どおり半数に。前景の線・ラベルは焦点の周囲だけ描画。

## 11. 空の状態・失敗時

| 状況 | 表示 |
|---|---|
| 絞り込みの結果が0件 | 「この条件に当てはまる学びは、まだありません」＋条件を1つ外すボタン |
| データを読み込めない | リスト表示（`map.html` 相当）へ案内。既存の作品ページへのリンクは常に有効 |
| WebGLが使えない | 背景を静止画にし、前景は通常どおり |
| 英語未翻訳のノード | 日本語の題を表示し、「日本語のみ」の印 |
| 予告中の作品 | 輪郭だけの星と公開予定の表示（出すかどうかは [09](09-open-questions.md)） |
