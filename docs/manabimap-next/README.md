# ManabiMap Next — 次世代知的探索プラットフォーム 基本設計

> **この資料群は設計専用です。** 本番の HTML・CSS・JavaScript・画像には一切手を入れていません。
> 変更は `docs/manabimap-next/` 配下の Markdown のみです。main へのマージは、レビューと合意ののちに別途判断してください。

## 何を決めるための資料か

科学・哲学・人類史・世界の物語などのシリーズが今後並行して増えていく前提で、
それらを **時間・概念・問い** の3軸で相互接続し、ユーザーが自由に操作・探索できる「知の世界」をどう作るか。
その基本方針（どの案で進めるか）を決めるための資料です。

## 決定事項（2026-11-15）

- **案B「知の地図帳（Atlas）」で進める。**
- 各シリーズは**別シリーズとして同じ銀河に同居**させる。哲学は**西洋哲学**と**東洋哲学**の2シリーズ。
- 今後は**科学・宇宙・物理・生命・AIの源流**などを構想。**興味に応じて雑多に広がる**前提で設計する。
  → 分野の空き枠を先に用意せず、新しいシリーズの位置は既存作品とのつながりから自動で決める（[04](04-information-architecture.md) 1章）。

残る確認事項は [09](09-open-questions.md) を参照してください。

## 結論（先に）

| 項目 | 提案 |
|---|---|
| 採用案 | **案B「知の地図帳（Atlas）」** — 既存ページは残したまま、その上に共通の知識グラフ層を1枚足す |
| 中心となる考え方 | 1つのグラフを、**銀河（概念）／時の河（時間）／問いの星座（問い）** の3つの見え方に投影する |
| 既存資産の扱い | 銀河UI・138億年年表・足あと・AIハンドオフ・全作品ページをそのまま再利用。作り直しはしない |
| 最初にやること | UIではなく **データの土台**（ID・概念辞書・問い台帳・時間の数値化・接続の根拠） |
| 本番への最初の影響 | フェーズ3まで発生しない（フェーズ1〜2は新規ファイルの追加のみ） |

採用理由の要点は、現状調査で分かった次の事実です（詳細は [01](01-current-state.md)）。

- 作品ページは **44本** あるのに、銀河に載っているのは **21本** だけ。哲学・東洋哲学・数学・EDU の **20本はデータ台帳の外**にある。
- 作品が参照する概念スラッグ **73個のうち63個が未定義**。タグ101個のうち複数作品で共有されるのは8個。つまり「概念でつなぐ」ための辞書がまだ無い。
- 年表の出来事160件は **HTMLの中にしか存在せず**、日付は文字列、レンズ分類は日本語タイトルをキーにした対応表。他シリーズから機械的に参照できない。
- 一方で、銀河の「レンズ＝問い」、年表の対数スケール、深さスライダーの3段階（全体→部のあいだ→一つの問い）など、
  **次世代構想の骨格になる設計思想はすでに実装済み**。足りないのは見た目ではなく、シリーズを横断する共通の台帳。

## 用語

| 用語 | 意味 |
|---|---|
| シリーズ | 作品のまとまり。例：ハルとおじいさん本編、EDU、哲学、東洋哲学、数学 |
| 作品（部） | 1本の「部」ページ。例：第17部 交換と協働、哲学シリーズ第1部 |
| 話 | 作品内のエピソード |
| 出来事 | 年表上の1点または1区間 |
| 概念 | 作品をまたいで再登場する考え方。例：外部記憶、注意経済 |
| 問い | 作品・出来事・概念を引き寄せる中心。ManabiMapの「知の重力レンズ」の焦点 |
| レンズ | 見る切り口。現行の銀河5種＋年表10種を統合したもの |
| Atlas（地図帳） | 上記すべてをノードとエッジで持つ共通の知識グラフ、およびそれを見せる新ビュー |

## 制約（この設計が守ること）

1. ビルド無しで動く静的サイト（GitHub Pages）という現行の運用を壊さない。
2. 既存URLを変えない。既存ページは、Atlasが無くても今まで通り動く。
3. 新シリーズの追加は「データを1か所に足す」だけで銀河・年表・問いのすべてに現れる。
4. 接続には必ず「なぜつながるか」の一文を持たせる。線を増やすこと自体を目的にしない。
5. 個人データはサーバーへ送らない（現行の「無言の足あと」の方針を継承）。
