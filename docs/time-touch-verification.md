# 時の宇宙：タッチ操作の実装と検証

2026-09-13。対象は `evolution.html`。歴史本文と既存画像の対応は変更していない。

## 操作

- 左右スワイプ：時代を移動。138億年の全体表示では最初のスワイプで少し拡大し、移動できる範囲へ入る。
- 一本指の上下：触れ始めた位置を基準に拡大・縮小。上へ動かすと近づく。
- 二本指：指の間隔に追従して拡大・縮小。中点の移動による時代移動も同時に扱う。
- 星をタップ：全体ではその時代へ近づき、拡大後は説明を開く。
- 空間のダブルタップ：その位置へ近づく。
- 指を離すと短い慣性。次に触れると止まる。OSの「動きを減らす」設定では慣性を無効化。
- マウスのホイール・ドラッグ、時代ボタン、位置スライダーも継続。空間にキーボードフォーカスを当てれば矢印・＋／−・Homeが使える。
- 通常画面では＋／−を維持。高さの小さい縦画面では重なりを避けて隠し、全体に戻るボタン・時代ボタン・一本指操作を残す。
- 空間内の縦動作は時間の拡大縮小に使う。通常のページスクロールは操作パネル等の空間外から行い、「詳しい年表として読む」でも退出できる。

## 尺度の表示

画面端をカメラの逆変換に通し、見えている過去の年数の幅／138億年を計算する。下部の全体地図には閲覧範囲を表示する。80pxのスケールは画面中央付近での年数を表し、対数表示なので他の位置で同じ80pxが同じ年数になるわけではない。

これは実時間に比例した移動や天体の物理シミュレーションではなく、過去を圧縮して近年を広げた時間ナビゲーション。未来の配置も実現時期・確率に比例しない別枠。背景の9万粒は装飾であり、出来事の件数や発生頻度ではない。

## 自動検証

`tests/evolution-touch.cjs` に回帰テストを保存。ローカル配信サーバー、Playwright、Chromeが必要。

```sh
node tests/evolution-touch.cjs
```

別の配信先は `PREVIEW_URL`、Playwrightの場所は `PLAYWRIGHT_MODULE`、スクリーンショット出力先は `QA_SCREENSHOTS` で指定できる。テストは画面上の表示・DOMとChromeのタッチ入力を使い、内部カメラを直接変更しない。

確認項目：

- 全体表示からの連続スワイプ／上下移動／ダブルタップ。
- ピンチの距離比と拡大率、指の中点にある年代の固定。
- 二本指から一本指への切り替えで急に倍率が変わらないこと。
- 星から始まるドラッグと意図したタップの区別。
- 範囲外の星が元の位置に残らず非表示になること。
- キャンセル時の停止、動きを減らす設定、キーボード、倍率上限。
- 390×844、320×568、1024×768、844×390の画面内に操作パネルが収まり、横スクロールがないこと。
- 詳細年表への退出、従来のマウス操作、JavaScript実行エラー。
- 既存118項目と未来5項目の維持。

## 未検証・次の確認

Chromeのタッチエミュレーションであり、実機iPhone／iPadのSafariを含む全端末での動作・描画速度を保証するものではない。実機で、ブラウザの戻るジェスチャーとの競合、ピンチ追従、縦横の回転、低性能端末の滑らかさ、VoiceOver操作を確認する。

また「操作できた」と「時間のスケールを理解できた」は別。初見の人に、宇宙の歴史の中で人類史がどれほど短いかを言葉にしてもらい、誤解（等間隔＝等年数、粒の密度＝出来事数）が生じないか確認する必要がある。
